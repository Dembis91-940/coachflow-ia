## Notes d'exécution

- **Outils** : Brevo (gratuit jusqu'à 300 contacts/jour), MailerLite (gratuit jusqu'à 1 000 abonnés) ou ConvertKit. Pour un premier lancement manuel : Gmail + brouillons programmés (Boomerang ou programmation native).
- **Segmentation** : envoyez les emails 1-4 à toute la liste ; les emails 5-7 aussi, mais ajoutez une version « relance » pour les non-ouvreurs (objet différent, même contenu).
- **RGPD** : chaque email doit contenir un lien de désinscription (les outils l'ajoutent automatiquement).
- **Mesure** : taux d'ouverture (> 40 % = bien), taux de clic (> 5 % = bien), taux de conversion de la page (> 2 % = bien pour une première vente).
- **Après J+7** : si le prix remonte à 87 €, gardez une séquence « evergreen » (les emails 1, 2, 3, 5 espacés de 3 jours) pour les nouveaux inscrits.
